# Simple C Project

A basic C project demonstrating modular code structure with multiple source files.

## Files

- `main.c` - Main program entry point
- `utils.h` - Header file with function declarations
- `utils.c` - Utility functions implementation
- `Makefile` - Build configuration

## Building

```bash
make
```

## Running

```bash
make run
# Or directly:
./program
```

## Cleaning

```bash
make clean
```

## Requirements

- GCC compiler
- Make utility
